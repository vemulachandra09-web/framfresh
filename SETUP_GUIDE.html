Setup Guide — New Laptop Installation

Prerequisites

  • Windows 10 or 11
  • Internet connection (to download installers)
  • Admin rights on the laptop
1

Install Python 3.11+

Download from https://www.python.org/downloads/

Check "Add Python to PATH" checkbox during installation!

Verify installation:

python --version
2

Install Node.js 18+ (LTS)

Download LTS version from https://nodejs.org/

Verify installation:

node --version npm --version
3

Install PostgreSQL 15

Download from https://www.postgresql.org/download/windows/

During installation:

  • Set superuser password to: 1234
  • Keep default port: 5432
  • Keep default user: postgres
  • Install pgAdmin 4 (optional, but helpful for visual DB management)

Verify installation:

psql -U postgres -h localhost -- Enter password when prompted: 1234 -- Type \q to exit
If psql is not recognized, add PostgreSQL to PATH:
C:\Program Files\PostgreSQL\15\bin
Go to: System Properties → Environment Variables → Path → New → paste the above path
4

Copy the project folder

Copy the entire farmfresh folder to the new laptop (USB drive, cloud, etc.)

Recommended location: C:\Users\{YourName}\farmfresh

Do NOT copy the backend\venv and frontend\node_modules folders — they will be recreated in the next steps.
5

Create the database

Open Command Prompt or PowerShell. Navigate to the project folder and run:

-- Step 5a: Create the database psql -U postgres -h localhost -c "CREATE DATABASE farmfresh;" -- Step 5b: Create all tables psql -U postgres -h localhost -d farmfresh -f database\schema.sql -- Step 5c: Insert seed data (admin user, products, sample users) psql -U postgres -h localhost -d farmfresh -f database\seed.sql
Enter password 1234 each time when prompted. Run these from inside the farmfresh folder.
6

Setup backend (Python + FastAPI)

-- Navigate to backend folder cd farmfresh\backend -- Create Python virtual environment python -m venv venv -- Activate virtual environment venv\Scripts\activate -- Install all Python dependencies pip install -r requirements.txt

Your terminal prompt should show (venv) after activation.

7

Configure database connection (.env file)

Create a file named .env inside the backend folder with this content:

DATABASE_URL=postgresql://postgres:1234@localhost:5432/farmfresh SECRET_KEY=farmfresh-secret-key-change-in-production ALGORITHM=HS256 ACCESS_TOKEN_EXPIRE_MINUTES=1440 REDIS_URL=redis://localhost:6379/0
If you set a different PostgreSQL password in Step 3, replace 1234 with your actual password in the DATABASE_URL above.
To create a .env file: Open Notepad → paste content → File → Save As → change "Save as type" to "All Files" → name it .env → save in the backend folder.
8

Start the backend server

From the backend folder (with venv activated):

uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

You should see: Uvicorn running on http://0.0.0.0:8000

Keep this terminal window open. The server must stay running.
9

Setup and start frontend (React)

Open a NEW terminal window (keep backend terminal running):

-- Navigate to frontend folder cd farmfresh\frontend -- Install Node.js dependencies npm install -- Start the React development server npm start

Browser should auto-open at http://localhost:3000

10

Test the application

Open browser and go to http://localhost:3000

Project structure

farmfresh/ backend/ app/ -- FastAPI source code (routers, models, schemas) venv/ -- Python virtual env (recreate on new machine) .env -- Database connection config (create manually) requirements.txt -- Python package list frontend/ src/ -- React source code (pages, components) node_modules/ -- Node packages (recreated by npm install) package.json -- Node dependency list database/ schema.sql -- Table definitions (run once) seed.sql -- Initial data: admin, products, sample users

Troubleshooting

Backend won't start / connection refused?

Check PostgreSQL service is running: Press Win + R → type services.msc → find "postgresql-x64-15" → click Start.

Password authentication failed?

Update the password in backend\.env — change 1234 in the DATABASE_URL to whatever password was set during PostgreSQL installation.

Frontend shows "Network Error" or blank page?

Make sure the backend server is running on port 8000 first. The frontend connects to http://localhost:8000 by default.

"python" is not recognized?

Python is not in PATH. Try py instead of python, or reinstall Python with "Add to PATH" checked.

"psql" is not recognized?

Add PostgreSQL bin directory to system PATH: C:\Program Files\PostgreSQL\15\bin

Port 3000 or 8000 already in use?

Kill the process using the port: netstat -ano | findstr :8000 then taskkill /PID {pid} /F

Daily usage — starting the app

Every time you want to run the app, open 2 terminal windows:

Terminal 1 — Backend

cd farmfresh\backend venv\Scripts\activate uvicorn app.main:app --reload --port 8000

Terminal 2 — Frontend

cd farmfresh\frontend npm start
